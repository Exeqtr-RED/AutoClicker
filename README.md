# Sekira Cliker

Автокликер для Android: плавающая панель поверх любых приложений, запись и воспроизведение тапов и свайпов. Работает через Accessibility Service — официальный API Android, **root не требуется**.

Название репозитория (`AutoClicker`) техническое — само приложение называется **Sekira Cliker**.

## Возможности

**Два режима работы**

- **Single Target** — автотап по одной выбранной точке с заданной задержкой
- **Multi Target with Swipe (MTWS)** — последовательность тапов и свайпов, у каждого действия своя пауза после него; список повторяется по кругу

**Запись пресетов**

- включи запись и выполняй действия по экрану — координаты и паузы записываются автоматически
- живой предпросмотр: записанный свайп сразу воспроизводится, список действий листается прямо во время записи
- счётчик «Записано: N» на кнопке «Остановить» — прогресс виден, не выходя из записи
- паузы записываются как есть — до 24 часов, ничего не обрезается

**Тонкая настройка**

- задержки в минутах и секундах: и между действиями MTWS, и периодичность запуска цикла
- «Разброс» (Single Target): реальная пауза выбирается случайно из интервала [задержка − разброс; задержка + разброс] — ритм становится неидеальным. Пример: задержка 396 мс, разброс 3 мс → каждая пауза случайно от 393 до 399 мс
- у каждого действия MTWS свои поля «Мин» и «Сек» (до 4 цифр — влезают сутки, 1440 минут)

**Перемотка MTWS (◀ / ▶)**

- **во время воспроизведения:** ▶ немедленно выполняет следующее действие списка (оставшаяся пауза пропускается), ◀ повторяет предыдущее — воспроизведение не останавливается и продолжается с выбранной позиции
- **когда пресет не запущен:** ◀ / ▶ запускают его с выбранной позиции — ▶ со следующего действия, ◀ с предыдущего
- границы работают циклично: на первом действии ◀ повторит его, ▶ после последнего начнёт список заново
- после остановки позиция сохраняется: ▶ продолжит со следующего за остановкой действия
- во время записи перемотка заблокирована; перемотанные действия попадают в счётчик кликов — это часть сценария

**Плавающая панель**

- старт/стоп, счётчик кликов и таймер сессии («27 · 03:12»); пауза удалена — время и циклы не прерываются
- строка прогресса MTWS: «Тап 2/5 · 3,4 с» — какое действие выполняется и сколько осталось до следующего; после последнего действия цикла отсчёт идёт до повторения списка; в простое — «Действий: 5»
- перемотка ◀ / ▶ вокруг кнопки play (для MTWS-пресетов)
- правка задержки Single Target прямо с панели: тап по строке «Задержка: N мс» → маленький редактор с клавиатурой → «Сохранить» действует и на идущий playback, без остановки
- имя выбранного пресета в шапке; тап по нему или по кнопке ☰ — выбор пресета прямо с панели
- выбор места тапа прямо с панели: тап по экрану — точка выбрана, приложение само возвращается в настройки
- нумерованные маркеры точек MTWS: перетаскивание и удаление прямо во время настройки
- кнопка прицела — скрыть/показать помощников текущего режима
- перетаскивание за шапку — позиция панели запоминается и переживает рестарт службы
- ✕ полностью скрывает плавающий интерфейс (панель, пузырь, крестик, маркеры, редактор задержки), но **не выключает службу** — права Accessibility никуда не исчезают; панель вернётся сама при следующем открытии приложения
- пузырь: короткий тап — развернуть панель, перетаскивание — переместить (позиция запоминается), удержание ~полсекунды — скрыть всё до открытия приложения

**Пресеты**

- сохранение, загрузка, удаление; хранение в JSON
- у каждого ST-пресета своя точка тапа — запекается в пресет при сохранении
- пресеты со старых версий читаются новыми без изменений

## Установка

### Готовый APK (рекомендуется)

1. Открой вкладку [Releases](https://github.com/Exeqtr-RED/AutoClicker/releases)
2. Скачай `Sekira_Cliker.apk` из последнего релиза
   - в релизах имя файла — через подчёркивания: GitHub сам заменяет пробелы на точки при скачивании, а подчёркивания не искажает; вложения в Releases доступны всем, артефакты во вкладке Actions (`Sekira_Cliker_debug.apk`) — только под учётной записью GitHub
3. Установи APK, разрешив «Установку из неизвестных источников» для браузера или файлового менеджера
   - релизный APK подписан фиксированным ключом — обновление ставится поверх без удаления данных

### Первый запуск

1. Открой приложение — оно попросит включить службу: **Настройки → Специальные возможности → Sekira Cliker**
2. Выдай разрешение **«Поверх других окон»** — нужна плавающая панель
3. Готово: кнопки в главном меню станут активны

Права не «слетают»: приложение никогда не выключает свою службу сама — кнопка ✕ лишь прячет плавающий интерфейс, а тумблер в настройках остаётся включённым. Если права всё же сбросились, это внешние причины: переустановка APK, кнопка «Остановить» в настройках приложения, «Ограниченная настройка» на Android 13+ или агрессивная экономия батареи MIUI/HyperOS (подробнее — в FAQ).

### Сборка из исходников

```bash
# Release — подписывается автоматически, APK появится в dist/
./gradlew assembleRelease
# -> dist/Sekira Cliker.apk

# Debug
./gradlew assembleDebug
```

CI: каждый push собирается GitHub Actions (Debug + Release APK). Публичный Release создаётся только тегом:

```bash
git tag v1.1
git push origin v1.1
```

## Как пользоваться

### Single Target

1. Главное меню → **Single Target**
2. «Выберите место для тапа» → тап по экрану → приложение вернётся на передний план само
3. Задай задержку между кликами (мс), при желании включи «Разброс»
4. Сохрани пресет и запусти — управление с плавающей панелью; задержку можно менять прямо с панели на лету

### Multi Target with Swipe

1. Главное меню → **MTWS**
2. Нажми запись и выполняй действия по экрану — паузы между ними запишутся как реальные
3. «Остановить» — пресет готов; задержку любого действия можно подправить полями «Мин»/«Сек»
4. Запуск: действия повторяются по кругу с заданной периодичностью
5. Перемотка: ▶ пропускает оставшуюся паузу и сразу выполняет следующее действие, ◀ повторяет предыдущее; когда пресет не запущен, ◀ / ▶ стартуют его с выбранного действия

Пауза после последнего действия записи отдельно не хранится — перед новым кругом цикл ждёт поле периодичности запуска.

## Разрешения

| Разрешение | Зачем нужно |
|---|---|
| Специальные возможности | инжект касаний (`dispatchGesture`) — официальный API |

| Вибрация | тактильный отклик кнопок панели |

## FAQ

**Права Accessibility слетают при каждом запуске?**

Исправлено: раньше кнопка ✕ вызывала `disableSelf()` — приложение само выключало себе службу, и тумблер приходилось включать заново. Теперь ✕ только скрывает плавающий интерфейс, служба остаётся включённой. Если права сбрасываются всё равно, причины внешние: переустановка APK или кнопка «Остановить» в настройках приложения; на Android 13+ тумблер может не включаться с надписью «Ограниченная настройка» — тапни «Разрешить ограниченные настройки» (Настройки → Приложения → Sekira Cliker → меню ⋮); на MIUI/HyperOS включи автозапуск и поставь экономию батареи «Без ограничений».

**Нажал ✕ — панель пропала, как вернуть?**

Так и задумано: ✕ прячет панель, пузырь, крестик и маркеры, но служба продолжает работать. Просто открой приложение — панель появится сама. Полностью выключить службу можно только в настройках Android: Настройки → Спец. возможности → Sekira Cliker.

**Куда делась кнопка паузы?**

Удалена: play работает как старт/стоп, время и циклы не прерываются. На месте паузы — строка прогресса «Тап 2/5 · 3,4 с» (для MTWS) или поле задержки (для ST). Счётчик кликов и таймер идут, пока идёт воспроизведение.

**Клики не срабатывают / панель не появляется**

- выключи и включи службу в Специальных возможностях
- проверь, что разрешение «Поверх других окон» выдано

**MIUI / HyperOS: служба сама выключается**

- включи автозапуск для приложения
- экономия батареи → «Без ограничений»
- закрепи приложение в списке недавних

**Записанные паузы обрезались до минуты?**

Исправлено: паузы до 24 часов записываются целиком, смещение пауз при воспроизведении устранено. Старые MTWS-пресеты пересоздай заново.

**Приложение не возвращается после выбора точки тапа?**

Исправлено: окно настроек поднимает сама служба — работает и на Android 10+, где запуск активити из фона заблокирован.
